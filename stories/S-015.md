## Situation
- A regional single customer view across channels, for wealth cross-sell and client management. It has been live since 2022 and enhanced continuously since.

## Task
- Led the 10-engineer onshore/offshore backend team; designed the data models; personally built core modules.

## Action
- I evaluated Cloudera as the data-processing framework.
- I designed and optimised 360° customer data models (transactions, accounts, balances), with KYC-relevant data handling.
- I led the data migration.
- I personally built the data-analysis module and the Spring Batch scheduled-processing jobs.

## Result
- APIs used by multiple business lines; the platform has run in production since 2022.
