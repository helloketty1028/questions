**行业适用**：BNK direct · INT transferable

## Situation
- Interviewers for technical-leader roles ask whether a delivery manager still writes and reads code.

## Task
- O1 + TL. Not full-time coding: everything outside delivery management is hands-on.

## Action
- I review code daily across the platform's ~50 code modules, with deep review of ~20 core modules.
- I co-design technical solutions with engineers for new requirements, and I own the architecture.
- I write the core modules when significant changes land:
  - in the payment-initiation hub: transaction initiation, the corporate- and user-role permission matrix, and payment-status processing;
  - in the customer-360 platform: the data-analysis module and the Spring Batch scheduled jobs.
- I support and resolve production issues.

## Result
- Qualitative: hands-on coverage across review, design, core code and production. No coding-time percentage.

## 讲法差异
- **ATL**：具体讲一个自己写的核心模块（例如权限矩阵）。
- **SM**：动手怎样帮助判断质量和风险，同时不成为瓶颈。
