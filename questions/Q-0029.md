## 考察意图
- 能否自上而下讲清：边界 → 输入 → 处理 → 下游 → 韧性 → 取舍
- 工程判断，不只是流程介绍

## 追问链
- How do you prevent duplicate payments?
- What happens if a downstream system or the SWIFT gateway is unavailable?
- Where is the bottleneck, and how do you scale?
- How do the services communicate?

## 陷阱 / 不要说
- **不报交易量**（UOB 交易量对外禁止，SA-08）
- **不说内部系统名**（CEW、C360、SCV-CCD）
- 不说 hub 负责 routing / 清算 / 结算（SA-02；03 CF-N4）
- 不用防御式开场（例如从上游缺陷讲起）
