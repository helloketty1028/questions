## 答题逻辑（中文，3–5 步）
1. SQL 是什么：查询和操作关系数据的声明式语言。
2. 常用：DML（SELECT / INSERT / UPDATE / DELETE）、join、聚合、子查询、窗口函数；DDL 和索引。
3. 和 Java 集成：JDBC PreparedStatement（防注入）、JPA / Hibernate 或 MyBatis、Spring @Transactional、连接池。
4. 性能：索引、执行计划、避免 N+1。

## 30s
> SQL is the declarative language for querying and changing relational data. Day to day: SELECT with joins, aggregations and window functions, plus INSERT, UPDATE and DELETE inside transactions. From Java, I use parameterised queries — PreparedStatement through JDBC, or JPA and MyBatis — so there's no SQL injection; Spring manages transactions with @Transactional, and a connection pool manages connections. For performance: the right indexes, reading the execution plan, and avoiding N+1 queries.

## ATL — 60s
> SQL is how we query and change relational data declaratively. The operations I use most: SELECT with joins, GROUP BY aggregations and window functions for reporting; INSERT, UPDATE and DELETE inside explicit transactions; and DDL for schemas and indexes. From Java, I always use parameterised queries — PreparedStatement through JDBC, or JPA and MyBatis — never string concatenation, to avoid injection. Spring's @Transactional sets the transaction boundaries, and a pool like HikariCP manages connections. When a query is slow, I read the execution plan first, then fix indexes, rewrite the query, or remove N+1 patterns in the ORM. In payments I also check isolation levels, because two transactions updating the same record is where duplicates come from.
